# Vault — conventions

A plain-markdown knowledge base (Karpathy style). No Obsidian. Synced by git.

## Navigation pattern
Start from `index.md`. Every folder has its own `index.md` listing what it
holds. To find something: read the `index.md` of that level, do not scan files
at random.

## Levels
- `raw/` — raw captures: sessions, transcripts, clippings. Nothing curated.
- `wiki/` — curated, linked knowledge. One idea per file, kebab-case.
- `outputs/` — artifacts generated by the agent (PDFs, HTML, notes).

## Rules
- Link between wiki notes with `[[file-name]]`.
- No secrets in the vault (they go to `.env`, which git ignores).
- Curating means moving from `raw/` to `wiki/` rewritten, not copying.
